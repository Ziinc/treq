# Installation

_How to install and set up Treq on your machine._

Download the latest version for macOS from the GitHub Releases page.

[View Releases](https://github.com/Ziinc/treq/releases)

## Initial Setup

1. Click **Select Repository** or the folder icon, and navigate to a Git repository, selecting the folder containing `.git`.
2. Treq verifies the repository, checks for existing workspaces, and initializes the `.treq` folder for metadata.
3. Optionally configure settings through the gear icon: branch naming pattern and terminal preferences. You can change these anytime.
