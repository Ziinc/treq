# Installation

_Get Treq installed and ready to use._

Download the latest version for macOS from the [GitHub Releases page](https://github.com/Ziinc/treq/releases).

## First Launch

**macOS**: If Gatekeeper blocks the app, go to System Settings → Privacy & Security, find the Treq message, and click "Open Anyway." Alternatively, right-click Treq in Finder and select Open.

## Initial Setup

1. Click **Select Repository** or the folder icon, and navigate to a Git repository, selecting the folder containing `.git`.
2. Treq verifies the repository, checks for existing workspaces, and initializes the `.treq` folder for metadata.
3. Optionally configure settings through the gear icon: branch naming pattern and terminal preferences. You can change these anytime.
